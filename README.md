# Mesto, интерактивная галерея с API

[Ссылка на опубликованный проект](https://mxdiev.github.io/mesto-ad/)

## Команды

- `npm run dev` – запуск локального сервера разработки
- `npm run build` – сборка проекта в папку `dist`
- `npm run deploy` – публикация сборки на GitHub Pages (через пакет gh-pages)
